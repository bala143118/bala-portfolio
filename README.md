## ⚡ Overview

This repository hosts the personal cyber security portfolio and CTF dossier of **Balamurugan S**. Built with an authentic retro-futuristic hacker aesthetic, it features real-time procedural audio effects, Matrix rain simulation, CRT scanlines, and an interactive detective evidence wall.

---

## 🚀 Key Features

* **Terminal BIOS & Interactive Shell:** Boot sequence simulation, real-time command execution (`help`, `ls`, `whoami`, `status`, `verify`, `exit`), and interactive terminal logs.
* **Detective Evidence Board:** High-tech cyber investigation room featuring verified CTF tournament medals, hackathon awards, and dynamic glowing reticle cards.
* **Interactive HUD Controls:** Keyboard keycap shortcuts (`[◄ PREV]`, `[NEXT ►]`, `[Z INSPECT]`, `[ESC RETURN]`) with tactile visual and sound feedback.
* **Procedural Sound Engine:** Web Audio API sound synthesis simulating paper rustling, terminal clicks, and laser scanning without external audio dependencies.
* **Canvas Matrix Digital Rain:** Optimized high-performance code rain backdrop streaming at low opacity for an authentic cyberpunk interface.

## 💻 Local Preview

To run locally using Python's built-in HTTP server:

```bash
python -m http.server 8000
```

Then navigate to:
* Homepage: `http://localhost:8000/index.html`
* Evidence Board: `http://localhost:8000/investigation.html`
